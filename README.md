# Financial Sales Dashboard

## Project Overview

This project was developed as part of the Data Analyst Internship Task 4.

The objective was to design an interactive dashboard for business stakeholders using Power BI.

## Tools Used

* Power BI
* Microsoft Excel Dataset

## Dashboard Features

* KPI Cards (Sales, Profit, Units Sold, Gross Sales)
* Sales Trend Analysis
* Product-wise Sales Analysis
* Segment-wise Sales Analysis
* Interactive Filters (Year and Country)

## Key Insights

* Paseo generated the highest sales.
* Government segment contributed the largest share of sales.
* Sales performance varied across different time periods.
* Interactive filters allow detailed exploration of data.
